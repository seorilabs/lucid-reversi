# Android 아이콘 수정 배포와 실행 근거 구축

## 목적과 승인 범위

사용자는 서리 로고가 남은 앱 아이콘 수정과 마켓 배포를 지시했고, 아이콘 수정 PR #163 뒤 누락 근거로 중단된 상태에서 **“마켓 배포까지 진행해라”**라고 재지시했다. 이 문서는 그 지시를 기존 Google Play 앱 `com.etlegame.reversi`의 공개까지 실행하기 위한 최소 범위로 구체화한다. 새로운 제품 동작·시각 방향·계정·결제 상품은 추가하지 않는다.

- 시작 소스: `b790cce85be2060834b2579e6b685cd23cfeba29`.
- 기존 공개 기준: Play Console에서 확인한 `v2.2.8`, 배포율 100%.
- 범위: 실제 시작 장면의 화면 좌표 입력 E2E, 격리 저장·고정 시드, 전체 기능 목록 v2, CI 연결, 실제 실행 근거, patch 태그와 Play internal → production → 공개 확인.
- 근거: `development-workflow`의 중앙 승인 E2E 도입 설계는 제품을 바꾸지 않는 테스트·CI·기능 목록 구축을 허용한다. `seorilabs-release-run`의 누락 근거 정지 조건에 따라 검증기를 우회하지 않고 실제 실행을 추가한다.

## 실행 구조와 실패 처리

실제 `godot/scenes/main.tscn`을 720×1280 SubViewport에 띄우고 버튼·셀·목록은 실제 입력으로만 조작한다. 저장·분석·광고·외부 링크·공유는 플랫폼 경계에서 격리한다. 규칙·AI·화면을 테스트 대역으로 교체하지 않는다. 엔진이 이미 받는 game_seed 인자에 선택적인 난수 소스 Callable을 연결해 E2E에서만 고정하고, 일반 실행은 기존 무작위 생성을 유지한다. 종료 시 BGM을 정지해 오디오 드라이버가 재생 자원을 반환하도록 한다. 시작 안내 → AI 대국 → 설정·로컬 대국·변형 규칙·퍼즐 → 종료 결과·기보·복기 → 취소·재시작·저장 복원을 검수한다. 기존 484개 smoke 검사도 유지한다.

`journey.json`은 모든 구현 기능을 덮고, 실패·오류 로그·시간 제한 초과는 실패로 종료한다. 같은 여정을 렌더링 모드로 실행해 실제 화면을 확인한다. 테스트를 통과시키기 위해 제품 동작·인수조건을 낮추지 않는다. 발견한 범위 내 결함만 최소 수정한다.

## 인수조건과 테스트

- AC-1: Android 아이콘 원본·일반·적응형 파일의 크기·알파·안전 영역이 맞고 서리 공용 로고가 없다.
- AC-2: 실제 시작 장면·좌표 입력·격리·재실행을 사용하는 E1~E8 여정이 기능 목록 전체를 덮는다.
- AC-3: 후보 SHA의 CI 전체 회귀와 독립 개발 환경 검수가 통과하고 중앙 before-build/before-deploy/before-release를 각각 실행한다.
- AC-4: 원장이 발행한 같은 versionCode를 내부 테스트에서 production으로 올리고 Console·API 공개 상태를 확인한다.

[테스트 계획](test-plan.json)은 L3, dev 전체 회귀이며 새 화면·UI 개편이 아니므로 redesign은 false다. CI 실행을 독립 근거로 사용한다. 에셋 수정은 기존 원본과 렌더·파일 검증을 대체 검증으로 사용하고, E2E 도입은 실제 실패 후 통과를 기록한다.

## 네이티브 경계

현재 기준 태그에 기능 목록이 없어 중앙 검증기가 네이티브 기능에 platform-first 하한을 부여할 수 있다. headless 대역을 실제 SDK 통과로 기록하지 않는다. 내부 업로드까지 개발 환경 근거로 진행한 뒤 실제 네이티브 호출·홈 아이콘·운영체제 경계에서 개발 환경으로 확인할 수 없는 항목만 특정해 Android 사용을 별도 소명한다. 이 문서와 배포 지시는 기기 접근 승인이 아니다. 승인 전에는 기기 조회·설치·실행·로그 수집을 하지 않는다.

## 배포와 복구

등록된 앱·업로드 키·WIF·원장을 재사용하고 public 저장소의 기존 x64 Linux 경로로 빌드한다. 수정한 태그를 옮기거나 번호를 재사용하지 않는다. 내부 테스트에서 실패한 후보는 원본 판정을 유지하고 새 후보로 교체한다. 기존 공개 앱과 저장 데이터를 삭제하지 않는다. 원본 증적은 NAS1dual에 해시 검증 후 보관하며 Git에는 이 문서와 필요한 작은 JSON만 남긴다.
